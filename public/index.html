订阅 Moodle 日历

将 Maynooth Moodle 的作业截止时间添加到你的日历。

1

获取 API key

  1. 登录 Maynooth Moodle ↗。
  2. 打开用户菜单 → Preferences → Security keys ↗。
  3. 创建或复制 Moodle mobile web service 的 Token。

没有此入口？查看 图文教程 ↗，或联系学校 Moodle 管理员。

2

生成订阅链接

API key 不会被保存。请勿分享密钥或订阅链接。

在日历中打开 ↗
3

添加到日历

iPhone / iPad

日历 → 日历 → 添加日历 → 添加订阅日历。粘贴链接，完成订阅。

Mac

日历 → 文件 → 新建日历订阅。粘贴链接，设置自动刷新频率。

Apple 官方说明 ↗
  1. 在电脑上打开 Google Calendar ↗。
  2. 其他日历 → ＋ → 通过网址（From URL）。
  3. 粘贴链接，点击「添加日历」。
Google 官方说明 ↗
  1. 打开 Outlook 网页版的日历。
  2. 添加日历 → 从 Web 订阅（Subscribe from web）。
  3. 粘贴链接，设置名称并保存。
Outlook 官方说明 ↗
请选择网址订阅，而非一次性导入 .ics。更新频率和提醒由日历应用决定。
